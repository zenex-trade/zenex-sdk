# Security

Report a vulnerability in this SDK in private, through the contacts listed in
the Zenex contracts' security policy:

https://github.com/zenex-trade/zenex-contracts/blob/main/SECURITY.md

Do not open a public issue or pull request for it, and do not post the
details in a public channel.

Include the SDK version, the function or binding affected, and the steps or a
test that reproduces the problem. That policy also states the bounty scope
and the behaviour the protocol accepts by design.
